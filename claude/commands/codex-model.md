# Codex モデル確認

Codexで使用しているモデルの設定を確認して表示してください。

## 手順

1. `~/.codex/config.toml` ファイルを読み込む
2. 以下の情報を抽出して表示:
   - 使用中のモデル名 (`model`)
   - 推論努力レベル (`model_reasoning_effort`)
   - その他の設定（あれば）

## 出力形式

```
📦 Codex モデル設定
━━━━━━━━━━━━━━━━━━━━━━━━
モデル: [モデル名]
推論努力: [レベル]
━━━━━━━━━━━━━━━━━━━━━━━━
```

設定ファイルが見つからない場合は、その旨を報告してください。
